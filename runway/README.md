# Launch Runway

Kanban board for solo-founder launch work (To Do / Doing / Done, **Later**, **Bucket List**).

**Open:** `marathon-board.html` in this folder, or use `../index.html`.

- Data: browser `localStorage` (`anshuli.runway.v2`)
- **Save file** / **Load file** for JSON backup
- **Export MD** for filtered task lists (not a restore format)

**Architecture & safety rules:** see `CURRENT.md` in this folder.

**Related:** X posting schedule lives in `../social/social-board.html`.
