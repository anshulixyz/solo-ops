Run it from the terminal or your agent

The same data, no clicking. Paste AGENTS.md into Claude, ChatGPT or Claude Code and it knows the files, the schema and these commands.

node solo.js today            # what is in play + idle reminder
node solo.js week             # tasks + posts for the next 7 days, every board
node solo.js add "Write the launch post" --proj launch --pri high
node solo.js done t5 --board runway
node solo.js boards add "Business as usual" --from sample
node solo.js social next     # next unposted post
node solo.js share todo      # markdown list to paste anywhere
Docs: README.md · AGENTS.md · data/SCHEMA.md · ⌘K opens the same commands on every page
