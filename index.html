Run it from the terminal or your agent

The same data, no clicking. Paste AGENTS.md into Claude, ChatGPT or Claude Code and it knows the files, the schema and these commands.

node marathon.js today            # what is in play right now
node marathon.js week             # tasks + posts for the next 7 days
node marathon.js add "Write the launch post" --proj launch --pri high --tags content
node marathon.js done t5         # by id or title
node marathon.js social next     # next unposted post
node marathon.js share todo      # markdown list to paste anywhere
node marathon.js theme set dusk
